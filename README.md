### What I'm working on
- **[A&S RTX Patcher](https://github.com/Felix-Chaos/Actions-and-Stuff-RTX-Patcher)** ([rtx.chaosdev.dev](https://rtx.chaosdev.dev)): Windows app that turns the Actions & Stuff Minecraft Bedrock pack into an RTX-compatible version with BetterRTX lighting, reflections and PBR materials. Patches live in the separate [AS-RTX-Patch-Library](https://github.com/Felix-Chaos/AS-RTX-Patch-Library).
- **[Chaos Dev Bot](https://bot.chaosdev.dev)**: Discord bot with a web dashboard. Leveling and level roles, moderation, honeypot anti-raid, support tickets and release tracking.
- **[Co2-Sensor](https://github.com/Felix-Chaos/Co2-Sensor)**: smart home dashboard on an ESP32 TTGO T-Display with SCD30 CO2 monitoring and MQTT integration into Home Assistant.
- **[NSA_Convertor](https://github.com/Felix-Chaos/NSA_Convertor)**: small Python tool that converts .nsa files to PDF.
